# Security policy

Please report a suspected vulnerability privately through
[GitHub’s private vulnerability reporting](https://github.com/sidko/static-search-ranker/security/advisories/new).
Do not open a public issue for a vulnerability before a fix is available.

The latest released version is supported on a best-effort basis. Include the
package version, a minimal synthetic reproduction, impact, and suggested
mitigation where possible. Do not include credentials, private indexes, or
customer data.
